# Ekspresi Esdeath AI

Taruh gambar ekspresi Esdeath di folder ini dengan format `.png`, `.jpg`, atau `.jpeg`.
Nama file menjadi nama ekspresi, misalnya `marah.jpg`, `senang.png`, `sedih.jpeg`, `bingung.png`.

Setelah menjawab, Esdeath memilih ekspresi yang paling sesuai dengan suasana atau aksi roleplay-nya,
lalu bot mengirim gambar itu sebagai stiker WhatsApp. Bila tidak ada gambar yang cocok, stiker tidak dikirim.
Gambar baru langsung terbaca tanpa restart.
